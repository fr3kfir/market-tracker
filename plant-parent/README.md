# 🌿 הורה לצמח (Plant Parent)

אפליקציית ווב (אפשר להוסיף למסך הבית בטלפון) שמזהה צמח מתמונה, מאבחנת בעיות ונותנת תנאי גידול — באמצעות Claude.

## מה יש באפליקציה
- **צילום או בחירה מהגלריה**, עד 3 זוויות לצמח + הערה חופשית ("העלים מצהיבים").
- **זיהוי**: שם בעברית, באנגלית ובלטינית, משפחה, רמת ודאות וחלופות אפשריות.
- **אבחון בריאות**: מזיקים, מחלות, השקיית יתר/חסר, חוסרים תזונתיים — עם סימנים, גורם וצעדי טיפול.
- **תנאי גידול**: אור, השקיה, לחות, טמפרטורה, אדמה, דישון, העברת עציץ, גיזום, ריבוי — מותאם לאקלים בישראל.
- **רעילות** לחיות מחמד ולבני אדם, וטיפים.
- **הצמחים שלי**: שמירת צמחים, כינוי, תזכורת השקיה וכפתור "השקיתי" (נשמר במכשיר).

## הרצה מקומית
```bash
cd plant-parent
npm install
cp .env.example .env   # הדביקו את ANTHROPIC_API_KEY
npm run dev            # http://localhost:5173
```

## פריסה ל-Vercel
1. New Project → אותו ריפו → **Root Directory = `plant-parent`**.
2. Environment Variables: `ANTHROPIC_API_KEY` (ואופציונלית `PLANT_MODEL`, ברירת מחדל `claude-sonnet-5-5`).
3. Deploy. בטלפון: שיתוף → "הוספה למסך הבית".

## מבנה
- `lib/diagnose-core.js` — הקריאה ל-Claude (ראייה ממוחשבת + פלט JSON מובנה).
- `api/diagnose.js` — פונקציית Vercel. `server.js` — שרת פיתוח מקומי.
- `src/` — React: סריקה, תוצאה, הצמחים שלי. התמונות מוקטנות בדפדפן לפני השליחה.
